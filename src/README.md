# WordPress Sites Admin Hub (Laravel)

## О проекте
Мини-система для хранения сайтов на WordPress:
- Информация о сайтах, серверах, кредах к wp-admin, кредах к CDN.
- Хранение секьюрных данных (логины/пароли CDN, серверов и админок).
- Минимальный CRUD на примере CDN.
- Базовые фиче- и юнит-тесты.

## Запуск (локально или в Docker)
### 1. Клонировать репозиторий
```bash
git clone <url>
cd admin-hub
```

### 2. Установить зависимости
```bash
composer install

```

### 3. Скопируй .env и настрой его
```bash
cp .env.example .env
```
